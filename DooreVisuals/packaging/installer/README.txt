DooreVisuals — установка в два шага

1. Распакуй архив в любую папку (целиком, не доставай файлы по одному).
2. Дважды кликни Install-DooreVisuals.cmd.

Нужен официальный Minecraft Launcher (запущенный хотя бы раз) и интернет.
Установщик сам поставит Fabric Loader, добавит профиль «DooreVisuals» и положит мод в папку mods.
Fabric API ставить отдельно не нужно — он внутри мода.

Потом открой лаунчер, выбери профиль «DooreVisuals» и нажми «Играть».
Удалить: убери профиль в лаунчере и файл doorevisuals-*.jar из папки .minecraft\mods.
